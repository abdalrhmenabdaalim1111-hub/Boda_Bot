# خطة تطوير متجر بودة والبوتات (V4)

## الرؤية
منصة واحدة (33 بوتاً + تطبيقات مصغّرة) — مرتبة، سريعة، بدون إعلانات،
مع بوابة اشتراك إجبارية في قناتي بودة وعبده، وتجربة موحدة عبر تيليجرام والويب.

## ما تم إنجازه (المرحلة 0–1)
- إصلاح لوحة التحكم (Console نظيف، تحليلات حية، RAM/CPU).
- بوابة القناتين (`@Stick_boda` + `@ebdo_4`) على كل البوتات + المتجر.
- تشغيل تلقائي لـ 34/34 بوت + إخفاء الأخطاء القديمة.
- `bots_registry.json`: 34 إدخالاً (33 ظاهرة + بوت المتجر مخفي عن المتجر).
- أوصاف احترافية + مميزات + فئات (7) + بوتات مميزة + ترتيب ثابت.
- `Bots_Folder/store_catalog.py`: مصدر واحد للفئات/الترتيب/الاستبعاد.
- `bot_store.py`: قائمة رئيسية، فئات، تفاصيل، بحث، إحصائيات، حالة اشتراك.
- `build_mini_apps.py`: متجر ويب (Hero، بحث، فئات، بطاقات، تفاصيل Sheet،
  شعار الاشتراك)، `catalog.json` (33)، SEO، 33 صفحة بوت.
- `app_template.py`: رأس/تذييل موحد، مشاركة، Apple meta، OG.
- `unified_middleware.py`: بوابة على callbacks، أوامر `/app` `/store`،
  ضبط وصف/أوامر البوت في تيليجرام، زر مشاركة في لوحة الأزرار.

## المرحلة 2 (2–4 أسابيع) — تطبيقات البوتات
1. **تطبيقات تفاعلية** لـ 10 بوتات إضافية (حالياً 33/33 already interactive):
   - توحيد UX: MainButton/BackButton/CloudStorage، تحميل skeleton.
   - إضافة "دليل استخدام" (3 خطوات) في كل تطبيق.
   - حفظ آخر إدخال (CloudStorage) لـ currency/transbot/cashier.
2. **بحث وفلترة** في المتجر (ويب): فلترة حسب الفئة/الميزة/اللغة،
   ترتيب (الأكثر استخداماً، الأحدث، أبجدي).
3. **صفحة تفاصيل بوت** (ويب) مع لقطات شاشة وروابط مباشرة.
4. **共用** "المفضلة" (localStorage) + "آخر 5 بوتات تم فتحها".
5. **Deep links**: `?start=<bot_id>` يفتح البوت مباشرة من المتجر.
6. **PWA**: manifest + service worker للاستخدام دون اتصال (قراءة فقط).

## المرحلة 3 (1–2 شهر) — منصة
1. **حساب موحد** (cross-bot identity) عبر Telegram initData (بدون توكن).
2. **تخصيص**: توصيات بوتات حسب الاستخدام (analytics).
3. **أداة إضافة بوت** (wizard) في لوحة التحكم: إضافة/تعديل/تعطيل.
4. **API عام** (read-only) لقائمة البوتات + الإحصائيات (مفتاح API).
5. **SEO**: صفحات landings (bot-wise) + structured data + sitemap.
6. **A/B testing** لبطاقات المتجر (عنوان/وصف/CTA).

## مؤشرات النجاح (KPIs)
- 34/34 بوت يعمل، 0 أخطاء Console.
- ≥ 90% من المستخدمين الجدد يكملون بوابة الاشتراك (verify).
- DAU/MAU ≥ 0.25 (حالياً ~0.29).
- ≥ 60% من جلسات المتجر تنتهي بفتح بوت.
- 0 إعلانات في التطبيقات (تطبيق إعدادات ads_config).

## الحوكمة
- `bots_registry.json` هو مصدر الحقيقة؛ إضافة بوت = حقل `hidden_from_store`.
- `store_catalog.py` هو مصدر الفئات/الترتيب.
- كل تغيير → pytest + build + git commit + push.
- لا تعديل على `.env`/`Data/` في git.
