## The 7 quality rules → enforced as code + tests

| # | Rule | Enforcement (testable) |
|---|---|---|
| 1 | Rewarded starts **only** from a user tap | `BodaAds.reward(cb)` refuses to run without a `userGesture:true` call path; app meta declares ad points; a lint/test asserts no auto-reward on `DOMContentLoaded` or observers |
| 2 | Core function never blocked by ad failure | `BodaAds` wraps everything in try/catch, returns `{ok:false, reason}`; tool UI works with `window[sdkName]` missing; test: mocked SDK rejects → tool still completes |
| 3 | No ads on the subscription-gate screen / during processing | Build-time: pages can declare `ads_excluded:true` (gate screens); runtime: no ad call while `body.processing` flag set; test: processing flag suppresses all ad paths |
| 4 | In-App soft defaults, then measure | Default `inAppSettings = {frequency:1, capping:12, interval:600, timeout:30, everyPage:true}` (≈1 ad / 12 h window — deliberately lighter than Monetag's 2/6min example); editable per profile; log `ad_shown/ad_error` and compare retention before/after (owner-approved step before raising) |
| 5 | Paste validation | Snippet parsed verbatim (zone + sdk extracted, snippet stored unmodified); domain allow-list (config, e.g. `libtl.com`) with explicit approve; reject/deny `eval(`, `document.write`, `location.replace` full redirects; size cap |
| 6 | Inject through the build, never hand-edit generated files | All injection in `tools/build_mini_apps.py` + `control_center/ads/injector.py`; regeneration preserves markers (fixes AUDIT §4 split-brain) |
| 7 | Never `alert()`, never block on ads | BodaAds contract + ESLint-style repo grep test for `alert(` in generated pages |

## Phase 1 — Security fixes (small, first). ~1 day

1. **Exclude the dashboard & admin artifacts from GitHub Pages** (test proves it):
   - Build Pages output to `webroot/` but upload from a filtered staging dir (new `.github/workflows/pages.yml` step or `webroot_publish/` generated by build) — excludes `dashboard/`, `.ads_backup_*`, any `data/` that isn't public.
   - Also stop generating `webroot/dashboard/` into the published tree; dashboard lives at `webroot/dashboard/` served only by `api_server.py` locally (it already is; Pages copy becomes unreachable).
2. **Replace blind localhost trust** (all with tests):
   - Validate `Host` == `127.0.0.1:<port>` (reject DNS-rebinding names).
   - For state-changing methods (POST/PUT/PATCH/DELETE): reject cross-origin `Origin` / `Sec-Fetch-Site: cross-site`, require a custom header `X-Boda-Local` **and** a generated local admin token (auto-created in a local file, auto-attached by the dashboard; printed once at startup).
   - Stop answering permissive preflights for non-dashboard origins; drop `ACAO: *` on API responses (keep it only for the dashboard origin `http://127.0.0.1:<port>`).
   - Keep `/api/track` open (public telemetry by design) but add initData-best-effort and rate limiting.
   - Add auth guard to the SSE log-stream route; redact token-looking strings in log endpoints; stop returning raw tracebacks (log server-side, return generic 500).
3. Fix `request.headers.get` → `.header()` at `api.py:1138,1374`.
4. Tests: cross-origin POST rejected (simulated `Origin: https://evil.example.com`), Host rebinding rejected, valid local flow (dashboard + curl with token) accepted, Pages artifact contains no `dashboard/`.

**Visible result:** `python -m pytest tests/` green; local dashboard still fully usable; `curl` without token → 403 with Arabic error.

## Phase 2 — Ad Studio core (parser, injector, BodaAds, formats). ~1.5–2 days

1. **Snippet parser** (`control_center/ads/`): accepts your exact formats (single/double quotes, protocol-relative `src`, `data-zone`, `data-sdk`); stores snippet **unmodified**; extracts `zone`, `sdk_name`; supports all three call formats exactly as you'll supply them (rewarded `.then`, popup `'pop'`, inApp settings object). Tests: zone/sdk variants, quotes, protocol-relative, malformed.
2. **Profiles model**: global default + per-bot override + per-category override (DB via `control_center/db.py`, mirrored to `Data/monetag_config.json` for the bot side + watcher hot-sync). Fields: snippet, zone, sdk, enabled formats, inApp settings (soft defaults per rule 4), reward hooks, allow-list overrides.
3. **Injection in the build**: extend `control_center/ads/injector.py` + `tools/build_mini_apps.py`:
   - marker blocks `<!-- AD:BEGIN slot=head id=… -->…<!-- AD:END slot=head -->` + `window.__BODA_ADS__` config block;
   - idempotent insert/update/remove; **fix carry-over** to read both copies (or make `webroot/` the single source and stop writing `webapps/` — owner question below);
   - atomic writes, timestamped backup, dry-run unified diff, one-click rollback, abort on invalid HTML, per-app size budget check (build fails if an app exceeds its budget);
   - consolidation decision for `webapps/` (AUDIT §4) applied.
4. **BodaAds runtime wrapper** (inline, zero dependencies, replaces today's ad paths in `ds_sdk.py`): `reward(cb)`, `popup(cb)`, `inApp()`, `ready()`; checks `window[sdkName]` is a function; try/catch; **reward callback only when the promise resolves**; `{ok:false, reason}` when SDK missing/blocked; double-tap guard; no `alert()`; never blocks core tool functionality (rule 2). Tests with mocked SDK (resolve/reject/missing/blocked).
5. **Validation** (rule 5): configurable domain allow-list (warn + explicit approve), `eval`/`document.write`/forced-redirect detection, snippet size cap. Extend existing `control_center/ads/validator.py`.
6. **Reward hooks** declared per app in meta (e.g. currency → unlock detailed chart; iqtest → detailed result; luckybox → extra spin; qrgen/logotext → high-res export; cvbuilder → clean PDF). Rewarded only from a user tap; interstitial only **after a completed result**; none on gate screens or during processing (rule 3).

**Tests added:** parser, injection idempotency/insert/update/remove/rollback/malformed-HTML, regeneration preserves markers (both copies), BodaAds behavior matrix, reward-only-on-resolve, allow-list/eval checks, size budget.
